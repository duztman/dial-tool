# Dial Tool

A parametric watch-dial design tool that runs on the web. Rings of ticks, markers, numerals, bands and text; hands; up to four windows; export to PDF, SVG and PNG.
Built to explore, present and produce watch dials.

**Use it: <https://duztman.github.io/dial-tool/>** (the released build, `main`), or <https://duztman.github.io/dial-tool/dev/> (the newest small push, `dev`, with its own saved dials and session), or open [`web/dial-tool.html`](web/dial-tool.html) from disk (one file, no install; Chrome or Edge for the fonts installed on the computer).

## Files

| File | What it is |
|---|---|
| `web/dial-tool.html` | **The tool, built**: one file with everything inside. Open it in a browser. |
| `web/src/` | Its source: `geometry.js` (settings, geometry, drawing) · `output.js` (SVG, PDF) · the window: `app.js` (the tool: its class, start and lifetime) with one file per part — `rows.js` (the tabs' rows as data), `panel.js` (panes, rows, the controller), `rings.js`, `hands.js`, `windows.js`, `colour.js` (with `ral.js`: RAL Classic and Design System+, the pop-out's RAL mode; `lume.js`: the research's lumes, the pop-out's Lume mode), `fonts.js`, `preview.js` (the canvas), `guides.js` (Guides and Shadows), `bar.js`, `cards.js` (Gallery, Versions), `export.js`, `mode.js` (show mode's switch), `night.js` (show mode's Night: the night filter and the lume glow over the watch's drawing), `icons.js` (every icon, R33), `ui.js` (shared helpers), `session.js` (links, saved dials, undo) · `moment.js` (the complications: one moment gives every window's text) · `watch.js` (the watch round the dial: cases, lugs, crown, straps, buckle, bracelets — one geometry, two paints; the Show Case's engine too) · `ink.js` (labels centred on their ink) · `opener.js` (the dial it opens with) · `wearos/` (the Wear OS export) · `css/` (the stylesheet, one file per layer and part, R32) · `main.js`. `web/build.mjs` packs them into the one file. |
| `web/fonts/` | The hundred open-licence font families the tool offers (SIL OFL, Apache 2.0 for Syncopate, free software for GL-Nummernschild; `README.md` and `licences/` inside; half of them are the font research's top tier, `docs/font-tiers-2026-10-16.md`). `web/fonts/ui/` holds the tool's own small fonts (Silkscreen for the tiny numbers; Dial Mono, the interface's mono, in two cuts; Dial Time; Dial Date), packed into the page by `build.mjs`; `web/fonts.mjs` fetches the families and writes `src/font_list.js`; `web/examples.mjs` writes the example dials (`src/examples.js`); `web/gallery.mjs` holds and writes the Gallery's dials (`src/gallery.js`); `web/links.mjs` turns settings into links and draws both lists' cards (`card()`). |
| `web/icons/` | The icon pipeline (R33, design canon §9): `fit.mjs` puts a new drawing on the icon grid and prints the code; `check.mjs` checks every icon in the running window (in `npm test`); `look.py` reads how heavy each line looks; `archive.mjs` keeps every icon as an SVG file in `svg/`. How: its `README.md`. |
| `web/test/` | `npm test` runs them all. `parity.py` draws every harness dial with the frozen `dial.py` and with the web geometry and compares the pictures; `frames.mjs` measures a window's frame all round and the stroker's roundness; `labels.mjs`, `linktrip.mjs`, `moment.mjs`, `wearos_test.mjs` test the labels, the links, the complications and the Wear OS export without a window; `window.mjs` uses the built page in Chromium (rows, ring list, clicks on the preview, fonts, exports, save and load); `same.mjs` keeps the look of the window (every element's computed style) and compares it, for changes that must not change the look. |
| `guide/` | The guidebook: its plan, text, checks, pictures and build (`make.sh`). |
