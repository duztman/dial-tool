# Versions

*15 Oct 2026. Every build, with the commit that holds it. Written for whoever needs an old version — to look at, compare or screenshot.*

Every version below is complete in the repo's history: nothing was deleted. On a clone, `tools/versions.sh` turns this table into tags (`v4.30`) and opens any version in its own folder:

```
tools/versions.sh tag          # a tag per row (local; `git push origin --tags` puts them on GitHub)
tools/versions.sh open 4.30    # → ../dial-tool-versions/v4.30/, open web/dial-tool.html there
```

Versions 1.x–2.x are the DrawBot tool (`dial.py`, frozen; now in `archive/drawbot/`). 3.0 onward is the web version (`web/dial-tool.html`). The commit is the last one of that version, with its follow-up fixes.
