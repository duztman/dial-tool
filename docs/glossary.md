# Glossary

The project's words, one line each, in two files — read the one the task touches:

- **[glossary-watch.md](glossary-watch.md)** — the watch and the dial: plate, hands, rings, windows and complications, type.
- **[glossary-tool.md](glossary-tool.md)** — the tool: the window's parts, number forms and the controller, the preview's switches, show mode, links and files, the code's names.

Use the words as they are defined. If Okay uses a term differently, ask, then change the line. A term's reason is the row in `decisions.md`; its look to the pixel is the code and `design.md`. The glossary before 21 Oct 2026, with its drawing details, is `archive/glossary-full-2026-10-21.md`; the DrawBot terms are in `archive/drawbot/glossary-drawbot.md`.
