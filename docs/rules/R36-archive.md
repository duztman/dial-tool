# R36 · The archive: every picture kept, on Okay's Mac

**The archive: every picture kept, on Okay's Mac** (Okay, 21 Oct 2026: "I keep screenshots whenever i can … I want to be able to trace the progression later"). Pictures live in **one place, the Mac folder** `~/Desktop/dial-maker/screenshots/` (Okay: "Mac folder only"), never in the repo. Every session **collects as it goes**, without being asked: what Okay sends through the chat (`/root/.claude/uploads/<session>/`, named `time-#item-word`) and its own check screenshots and crops, per version; at the **end of the session** they are filed into the Mac folder with a README row each (what it shows, his words), through the link to his Mac. If the session isn't linked, they go to him as one zip in the chat, to be filed at the next linked session. **Update pages** every ten steps (Okay: "Made every ten big steps"): 4.90 has one; the next is v1.0, then 1.10, 1.20 …; a page says what changed with its pictures, kept in the Mac folder and as a private artifact. **The story page** (Okay, 25 Oct 2026: "put this html on the root for all upcoming and previous versions to use"): `screenshots/dial-tool-story.html` — every session from 12 Oct 2026 (beta 4.3) on, Okay's side left, Claude's right, test renders folded under each; built by `screenshots/_story/build.py` (its `README.md` says how). Each session that files pictures adds its `ses(...)` to `_story/data.py` and rebuilds; `missing []` is the check. Paths in it are percent-encoded (a `#` in a name cut the link). The folder's root holds only session folders, `progression/`, `_story/`, `_archive/` (loose files and zips) and the page. **The progression strip**: the same views in every step's last build — the tool as it opens and Okay's watch at 10:10, at an iPad's landscape size — in the Mac folder's `progression/` with an `index.html` to move through them (`node test/progression.mjs <from> <to> <folder>`, #503); each step adds its frame when it is released.
