# R10 · Text is shaped by HarfBuzz and becomes outlines

**Text is shaped by HarfBuzz and becomes outlines** (`geometry.js`), so font, tracking, features, axes and language all reach the vectors. The export option *live text* writes the same shaped text as text instead, placed from the outlines' bounds, so both land in the same place; cuts become clipping masks. Preview and production masks are always outlines.
