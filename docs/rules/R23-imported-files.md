# R23 · Imported files (SVG, PDF, AI)

**Imported files (SVG, PDF, AI)** — not built in the web version (build list #50); when they are: drawn pointing up (12 o'clock); the artboard's centre is the anchor — a hand's pivot, a marker's centre. Only the first page counts. Fills are ink; plain white fills cut; strokes become outlines (R4); clipping is ignored; text, images and gradients are skipped and reported in the Export log.
