# R34 · No band-aids: one need, one mechanism

**No band-aids: one need, one mechanism** (Okay, 19 Oct 2026: "no band-aid solutions, if new prompt is something new, just check code at how we do similar things, if none exists, make this a new law. Robust, future proof. Remove conflicting laws or edit appropriately"). Before building an ask, find how the tool already does the like (a row form, a heading-line control, a note, a pane) and use that. If nothing does, build it as a mechanism others can use and write it here as a rule; a rule it contradicts is edited or removed in the same push. A condition, a value or a selector written for one place only is the sign to stop and look again.
