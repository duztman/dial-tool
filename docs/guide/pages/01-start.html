1. DrawBot 3.132 or newer, from drawbot.com.
  2. dial.py from github.com/duztman/dial-tool. Branch main is the released version; dev is the newest work.
  3. Open dial.py in DrawBot and press ⌘R. The window opens.

Knockouts and hollow shapes are cut by combining outlines. DrawBot’s own routine is slow; skia-pathops is 2 to 14 times faster.

In DrawBot: Python → Install Python Packages → skia-pathops → Go. The Export log then opens with “shape combining: skia-pathops”.

Settings are stored as you work. Press ⌘R again, or quit DrawBot: the last session reopens as you left it.

Export → Save… writes a named copy; Load… opens one. The nine dials in this book come as such files.

Every length is a millimetre, drawn at true size. Radii are measured from the dial’s centre.

Clock angles, growing clockwise. 90° is 3 o’clock, 180° is 6, −90° is 9.

Everything exported is a filled outline, never a stroke. A 0.12 mm tick is 0.12 mm in Illustrator.

The ring list is the stacking order. The top ring is drawn last, in front of the others.

 {{strip:first}} It runs only inside DrawBot. The window, the fonts and the export all come from DrawBot’s own Python. The canvas preview needs macOS 14 or newer. Older systems get the PDF preview, and the log says why.
