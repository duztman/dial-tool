Dial
Tool

A watch dial is a few things repeated round a centre. Dial Tool draws it that way: a list of rings, three hands and a date window, in millimetres, as clean vectors for print, etching and laser.

01

Start

Dial Tool is one Python file that runs inside DrawBot, a free drawing app for macOS.

Install

Three steps, one file.

  1. DrawBot 3.132 or newer, from drawbot.com.
  2. dial.py from github.com/duztman/dial-tool. Branch main is the released version; dev is the newest work.
  3. Open dial.py in DrawBot and press ⌘R. The window opens.
Speed

One optional package.

Knockouts and hollow shapes are cut by combining outlines. DrawBot's own routine is slow; skia-pathops is 2 to 14 times faster.

In DrawBot: Python → Install Python Packages → skia-pathops → Go. The Export log then starts with shape combining: skia-pathops.

Memory

Nothing to save.

Settings are stored as you work. ⌘R again, or quitting DrawBot, keeps them.

Unit

mm

Every length is in millimetres, drawn at true size. Radii are measured from the dial's centre.

Angle

0° = 12

Clock angles, growing clockwise. 90° is 3 o'clock, 180° is 6, −90° is 9.

Shape

Fills

Everything exported is a filled outline, never a stroke. A 0.12 mm tick is exactly 0.12 mm in Illustrator.

Order

Top first

The ring list is the stacking order. The top ring is drawn last, in front.

Output

Outlines

Numerals leave as outlines: no fonts needed to open or print. Live text is an option.

Number

Slider, field and stepper show one value.

{{ui:dial:field:3:len,w}}

Drag for a rough value, type for an exact one, step for the last hundredth. Typing a value past the slider's end extends the slider.

03

Rings

A ring repeats one thing round the centre, at its positions. A dial is a short list of them.

{{strip:exploded}}
The idea

One dial, five rings.

The diver on page {{page:diver}}, taken apart. Each ring does one job; the list stacks them. Nothing here is special-cased: the triangle is a markers ring with a count of one.

The list{{rings:diver}}
Kind

Four kinds, changeable at any time.

Ticks and markers repeat a shape. Numerals repeat a label. A band is colour between two radii. Every ring carries every setting, so changing a ring's kind loses nothing.

04

Positions

Where a ring puts things. Six numbers describe almost any track, scale or set of hours.

{{strip:positions}}
Count · Start · Span

A full turn spaces evenly. An arc marks both ends.

{{ui:strip:positions-4:0:count,start,span}}

With Span 360° twelve positions sit 30° apart. With less, the first and the last position sit on the ends of the arc: Count 10 over 270° is a scale from 0 to 9.

Every · Offset · Skip those instead

Use some of the positions.

{{ui:strip:positions-2:0:every,offset,invert}}

Every 3 keeps the cardinals. Tick Skip those instead and the same setting keeps the other eight. Offset moves the starting point.

Radius

Outer edge.

For ticks, markers and bands, Radius is the outer end. For numerals it is the centre of the text.

05

Marks

Ticks and markers share one set of shapes. Markers add a first position that can differ.

{{strip:shapes}}
Shape

Bar, wedge, dot — or your own file.

{{ui:strip:shapes-5:0:shape,len,w,round_out,round_in,wall}}
Wedge

One number.

Inner width × sets the inner end as a share of the outer: 0 is a triangle, 1 a bar, more than 1 widens inward.

Corners

True fillets.

Round outer and Round inner are radii in mm, tangent on any angle. Hollow wall leaves an outline of that thickness.

12 o'clock

The first position.

A markers ring can draw it the same, double (with a Gap), as a triangle, or not at all; Scale × sizes it.

06

Give way
Bands

How a ring reacts to the rings above it, and how to lay colour.

{{strip:giveway}}
Give way {{ui:strip:giveway-2:1:skip,knock,clear}}
Skip where

Leave out positions that are taken.

The ring drops its own positions wherever the chosen rings above already have a mark. Minute ticks that stop for the hour markers; fine ticks that stop for the minute ticks.

Knock out

Cut a gap round what is above.

The ring is cut back by Clearance mm round the shapes above it: markers, markers and numerals, or everything. The date window always clears every ring, by its own Print clearance.

{{strip:bands}}
Band

Colour between Radius and Radius − Band width.

Count 1 is a full ring. More positions cut it into segments that tile the span; Fill % is how much of its step each segment covers.

Uses

Rails, zones, sectors.

Railroad rails are two bands 0.12 wide. A band as wide as its radius reaches the centre: with Every 2 that is a sector dial. A short span is a red zone.

Numerals

One label per position, from a built-in set, a count, or your own list.

{{strip:labels:0-5}} {{strip:labels:5-8}}
Labels

Eight sets.

{{ui:strip:labels-6:0:labels,num_from,num_step,num_digits,start}}
{{strip:placement}}
Placement

Four ways to sit.

On path sets each letter on the circle with the font's own spacing; below 3 and 9 it flips to read left to right.

Numbers

Labels that count.

From First number by Step, padded to Digits: 05, 10 … 60 for a minute ring, 0, 10 … 90 for a scale. Negative steps count down.

Custom

Your own list, comma-separated.

One entry per position. An empty entry leaves that position empty — which is how two rings can share one circle of hours.

Type
Nudge

Each numerals ring has its own type. Each numeral can be corrected by eye.

{{strip:type}}
Per ring

Any installed font.

Family, then style. There is no fonts folder: the tool reads what macOS has.

Correct one numeral at a time.

Stored per position. Reset this, or Reset all.

Typical

Even the weight.

Two-digit numerals look heavier. Size × 0.92 on 10, 11 and 12 evens them; Radius −0.2 pulls a wide 12 in.

10

Date window

A hole in the plate that shows the date disc, with an optional printed frame.

{{strip:date}}
The window at 3 {{ui:strip:date-0:date:da_on,da_at,da_r,da_w,da_h,da_round,da_frame,da_clear,da_day,da_size}}
Clearance

Print keeps away from the hole.

Every ring is cut back by the frame plus Print clearance. Markers and numerals leave the date's position empty altogether, as on a real dial.

Type

The day uses the top numerals ring's font.

Shows is the day drawn on the disc; Text % of height sizes it. The frame and the day share the Print colour.

Production

A cut line.

In a production mask the aperture is drawn as an outline to cut or drill to.

Classics

Nine dials drawn after well-known types, by eye. Approximations, not measured copies.

How to read them

Each page is a recipe.

Rings are listed top first. Only what differs from a newly added ring is printed; everything else is at its starting value. The values are the ones that drew the picture.

Presets

Load them.

Each dial is a settings file in docs/guide/presets. Export → Settings → Load… opens it, ready to change.

Fonts

Named as on macOS.

DIN Alternate, Futura, Helvetica Neue, Bodoni 72. These pages were rendered off-Mac with similar open fonts, so numerals differ slightly.

Files
in and out

Vectors at true size, a one-colour mask for production, and your own shapes coming in.

{{strip:output}}
Export {{ui:strip:output-2:dial:out_production,out_mirror,out_live_text,out_dpi,out_seconds,out_fps}}
PDF · SVG

Vector, true size.

For Illustrator, print, the press, laser. A 30 mm dial opens 30 mm wide.

PNG

At your dpi.

Film for toner transfer. 30 mm at 600 dpi is 709 pixels; a 0.09 mm tick is two of them.

MP4 · GIF

Hands moving.

From the set time, for Clip seconds at Frames per s, in the chosen beat.

Production

One colour.

No plate, no hands; every ring black; the date aperture a cut line. Mirror flips it for transfer.

Live text

Off by default.

Keeps numerals editable in PDF and SVG. The fonts are then needed, and on-path text becomes one object per letter.

In

SVG, PDF and AI, for markers and hands.

Draw pointing up, at 12 o'clock. The artboard's centre is the anchor: a hand's pivot, a marker's centre. Black is ink; white shapes cut holes; strokes become outlines.

Before importing

Outline text, flatten effects.

Text, images and gradients are skipped, and the Export log says so. Save AI files with “Create PDF Compatible File”. Only the first page counts.

Recipes
Help

Short constructions to build on, with a dial that uses each. Below: what to check when something looks wrong.

Track

Railroad.

Ticks, Count 60. Two bands 0.12 wide: one at the ticks' Radius, one at Radius − tick Length + 0.12. Page {{page:california}}.

Track

Fifths of a second.

Ticks Count 60 above ticks Count 300. The 300 Skip where: all marks above.

Hours

Cardinals only.

Every 3. For the other eight: Every 3 and Skip those instead. Page {{page:sector}}.

Hours

24-hour ring.

Numerals, Labels Custom: 24, 13, 14 … 23, at a smaller Radius and Size. Page {{page:field}}.

Hours

Two fonts, one circle.

Two numerals rings on one Radius; each Custom list leaves the other's positions empty. Page {{page:california}}.

Minutes

05 to 60.

Numerals, Labels Numbers, First number 5, Step 5, Digits 2, Start 30°. Page {{page:sector}}.

Text

A wordmark.

Numerals, Count 1, Start 0° or 180°, Labels Custom, Placement on path. Page {{page:dress}}.

Colour

A gap round numerals.

A band below the numerals; Knock out: markers & numerals above; Clearance 0.3.

Colour

Sector dial.

A band, Count 12, Every 2, Band width equal to Radius. Page {{page:sector}}.

Lume

An opening.

Hollow wall 0.15 to 0.25 on a marker or a hand leaves the outline as a frame.

A ring is gone

Three places to look.

Its checkbox in the list; its Every and Offset; and whether it skips positions that a ring above takes.

No numeral at 3

The date took it.

Markers and numerals leave the date's position empty.

Diameter

Nothing else moves.

Radii and hand lengths are millimetres from the centre, as on a real movement. Change them ring by ring.

Slow

Check the log.

It should say shape combining: skia-pathops. If not, install it: page {{page:start}}.

Start over

Defaults.

Export → Settings → Defaults. The last session is in ~/Library/Application Support/DialTool/last.json.

When something is wrong

Read the log, compare the previews, send both.

  1. Open Export and read the log. At launch it says preview: canvas and all controls connected.
  2. If the preview looks wrong, switch Canvas to PDF and compare.
  3. Send a screenshot and the log. If the window doesn't build at all, run tools/dial_probe.py in DrawBot and send its report.
